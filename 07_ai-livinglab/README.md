# 07 · AI 민원 안내 검증 계획

> 기능보다 "무엇이 좋아져야 성공인지"를 먼저 정한 서비스 검증 계획입니다.

- **기간**: 2026.10 – 11 · 개인 과제 (AI리빙랩 수업)
- **내용**: 문제 발굴, 사용 시나리오 설계, 검증 지표 설계

## 시험 설계
- **대상**: 동주민센터 1곳, 안내 직원 6명 (신규 3 · 경력 3), 이사 관련 가상 문의 10건
- **방법**: 직원마다 AI 없이 5건, AI와 함께 5건. 순서를 교차해 학습 효과를 줄임
- **일정**: 1주 준비 → 2–3주 현장 시험 → 4주 분석 (로그 · 채점 · 설문 · 인터뷰)

## 성공 기준

| 구분 | 지표 | 성공 기준 |
|---|---|---|
| 효율 | 안내 준비 시간 | 평균 30% 이상 단축 |
| 포착 | 필수 확인사항 포착률 | 85% 이상 (AI 없이보다 +15%p) |
| 준비 | 준비서류 안내 충족도 | 90% 이상 |
| 신뢰 | 출처 일치율 | 95% 이상 |
| 안전 | 잘못된 안내 | 중대 오류 0건, 경미 5% 이하 |
| 수용 | 직원 만족 · 사용 의향 | 5점 만점 평균 4.0 이상 |
